# EC200U 当前C固件上报修复

用户已授权直接优化当前固件并实板联调。保持STM32控制、K230串口、LED/风扇默认关闭与现有外设；不刷回MicroPython，不改变接口1.0.0。优先上行，不增加未经验证的远程动作。

1. 私有备份当前芯片镜像及源码，核对载板和实际串口；从已有授权备份恢复可用配置时，仅写受排除的私有配置，不显示秘密。
2. 先测试纯C的AT流解析、有效性/遥测序列和超时，再实现USART6环缓冲与独立任务；先验证真实AT/型号/SIM/注册能力。
3. 根据实机支持的EC200U MQTT/TLS能力，加载CA、核对时间与服务器验证，完成真实QoS1上报；身份配置与源码分离。
4. 对接已有云端的正式契约消费者；原有旧主题保留兼容，不改冻结公共字段。云端访问/部署条件不足时，仍完成固件及软件检查并如实记录。
5. 实际构建、保存固件哈希、烧录校验，验证原有任务运行与实际发布/接收；硬件不响应时先记录电源/AT口证据，不编造成功。

每步单独记录代码完成、软件验证及硬件结果。禁止泄露凭据、关闭TLS验证、模拟充当真4G、未经授权公开部署或付费。完成正常上报后再开展连续运行、断网恢复与远控验收。
