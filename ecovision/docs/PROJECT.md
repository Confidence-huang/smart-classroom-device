# EcoVision 绿智微视：原型项目说明

版本：1.0.0；建立日期：2026-11-12；负责人：总控。时间均为 Asia/Shanghai。

## 当前执行基线

2026-11-14 晚启动，2026-11-29 交付。交付模拟沙盒、嵌入式系统、云端的最小完整原型：K230 本地识别人 → STM32 控制 5V 风扇与 LED → **移远通信 EC200U 真实 4G** 上报 → 云端授权手动控制 → 终端 ACK。断网时本地控制继续运行。

本次用户指令与本文件每日计划为当前排期依据；《EcoVision二十天原型机完整实施方案.md》仅作技术参考；V4.1 策划书为长期背景。当前没有发现其他新版每日计划，不把旧 D1—D20 平移为执行计划。

预算总额≤5000元，优先复用已有 K230、STM32、EC200U。旧方案4800元为计划预算、1600元为其中的阶段额度，不能叠加；实际已用金额待核。不得自行付费、公开部署或写入凭据。

| 目录 | 负责人 / 边界 |

第一版公共契约见 INTERFACES.md，冻结版本1.0.0。模块只能修改本目录，不能自行改公共字段、主题、协议或优先级。接口建议提交总控后统一修订。不要默认其他聊天的交付已合入。

原型限定固定视场0—5人、低压负载。空调红外仅在核心通过后作为加分项；不含强电施工、教室泛化精度、节能15%证明、CO₂融合、PMV、OTA和复杂执行器。温湿度驱动未确认前允许先用明确标注的模拟量联调，不计硬件验收。
