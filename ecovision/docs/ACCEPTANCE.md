# 核心验收方法

本文件为验收计划，所有硬件条目初始状态为未测试。测试记录须含日期、操作者、实物型号、固件/模型/契约版本、真实/模拟标记、输入、预期、原始日志、实际结果及问题单。软件单测不能替代硬件验收。

| ID | 操作与样本 | 通过条件 / 证据 |
|---|---|---|
| A00 契约 | 运行INTEGRATION中的离线检查 | 全部样例符合结构、CRC向量与场景关系；仅属公共合同检查 |
| A01 上电 | 完整硬件断电重启10次 | 每次输出默认0、boot_id变化、AUTO；旧手动不恢复；启动与GPIO记录 |
| A02 视觉 | 固定视场0..5人，各10段独立片段，每段1个稳定结果 | 共60样本，MAE目标≤0.5人，逐人数及困难场景报告；不泛化到教室 |
| A03 本地链路 | 真人进入20次、离开20次 | 进入至LED≤5秒；连续有效无人30秒+处理≤5秒后关；录像与串口/GPIO日志 |
| A04 温控 | 真人占用；实际传感值跨过28/27℃阈值，各5次 | 连续5秒后正确启停，回差区不抖动；若调演示阈值需记真实值与配置；注入温度单独标模拟 |
| A05 UART | 错CRC、非ASCII、半包、粘包、128字节边界/超长、200ms超时、重复/倒序/回绕、两端分别重启 | 不崩溃、不误更新人数/计时；旧会话不生效；新握手恢复；记录原始字节及解析计数 |
| A06 4G上报 | EC200U接SIM，终端不用Wi-Fi/电脑网络转发，连续1小时 | 云端5秒周期样本完整率≥95%；以本地计划周期样本数为分母，事件上报不抵消缺失；记录注册/TLS/序号、断链与证据照片 |
| A07 远控 | 手机授权页面发20条有效命令 | 20条均正确执行，至少19条≤10秒收到ACK；逐条cmd_id、发送/接收/ACK与输出对应；正常网络条件说明 |
| A08 命令防护 | 过期/未来/未知版本/保留消息/错设备/旧boot/旧epoch/无可信时间/超界参数/同ID冲突 | 拒绝且输出与租期不变；对应reason可追踪，未授权/不可关联消息按契约丢弃 |
| A09 幂等 | 同ID同内容在执行后、过期后、按键后重复；另测32容量、ACK丢失 | 缓存内重发相同最终ACK，物理动作次数不增加、租期不延长；满容量BUSY不执行；TTL清理后旧命令不生效 |
| A10 本地优先 | REMOTE期间长按，再下发新旧远程命令；短按回AUTO，注入旧epoch命令 | LOCAL_OFF持续0，远程不能解除；短按后旧epoch也拒绝；按键消抖/长短按无双触发 |
| A11 断网 | 禁用Broker/网络10分钟；既有REMOTE租期在断网内到期；恢复网络 | 本地视觉控制不阻塞，租期正常结束；5秒/15秒失效显示正确；恢复后目标120秒内收到当前状态，无旧队列指令执行；记录失败次数及退避 |
| A12 感知故障 | 分别拔视觉UART/温湿度模块，穿插无效帧与重复帧 | ≥5秒视觉过期、≥10秒温度过期；无效不当无人；AUTO连续关键故障60秒关闭；REMOTE仍按租期；故障恢复重新确认 |
| A13 云端权限 | 无登录、错误设备凭据、访问他设备主题、过期遥测、遗嘱乱序、ACK迟到 | 非授权不能控制；STALE禁按钮，旧会话不覆盖新状态；不在前端暴露管理员秘密；运行模式无图像上行 |
| A14 沙盒 | 加载正常/无效/过期/重复/断网公共样例 | 画面显著标模拟；共用字段/单位/优先级；状态与时间推进可重现；不作为A02/A06实测证据 |
| A15 8小时 | 按下文运行并归档原始日志 | 无不可恢复卡死；本地周期日志完整率≥95%，复位次数及原因全记录；计划断网不从本地日志分母删除 |
| A16 交付 | 另一人从断电状态按指南重现 | 可启动实物与私有云/沙盒；有可烧录固件、模型/版本、接线、非敏感配置、用例、8小时日志、演示视频、问题清单 |

8小时建议分段：0—1h自动有人/无人；1—2h温控及回差；2—3h远程及租期；3—4h本地接管及重复命令；4—5h断网10分钟/恢复；5—6h感知故障及恢复；6—8h正常循环。监控从开始连续计时；人为重启/异常重启也记录，不能删掉失败区间重算。硬件电源/模式/序号/心跳及独立观察记录均须保留。8小时中如修改固件/接线/阈值，另起完整测试窗口。

判定可用PASS / FAIL / BLOCKED / NOT_RUN，缺实物或凭据为BLOCKED而非PASS。演示当天云不可用时记录远控未通过，不能用历史录像冒充当场通过。阈值与精度为本原型目标，未达标如实提交，不声称节能收益或机械转速已经验证。
