# 模块接线交接：NUCLEO-F413ZH

2026-11-23。交接给负责实物接线的队友。仅用已焊接的**内侧排母**，按 MCU 名、Arduino 丝印与 CN 编号三者核对；不是外侧 Morpho 未焊孔。断电后插拔。当前 PR 是待接线验收候选，不代表以下模块全部已经通过实测。

## 固定信号接线

| 模块端子 | STM32 / 内侧丝印 / 物理孔 | 配置与注意 |
| --- | --- | --- |
| WS281x 灯环 DI | **PB11 / D35 / CN10-34** | TIM2_CH4 AF1，800kHz，DMA1 Stream7 Channel3；DO 留空 |
| TB6612 PWMA | **PB5 / D22 / CN7-13** | TIM3_CH2 AF2，20kHz |
| TB6612 AIN1 | **PB10 / D36 / CN10-32** | GPIO，固定正转方向控制 |
| TB6612 AIN2 | **PE0 / D34 / CN10-33** | GPIO |
| TB6612 STBY | **PF15 / D2 / CN10-12** | GPIO，上电低，禁止直接常接高电平绕过关闭 |
| 干簧管 DO | **PE13 / D3 / CN10-10** | GPIO 上拉、30ms 消抖；不用此脚 TIM1_CH3 |
| BH1750 SCL | **PB8 / D15 / CN7-2** | I2C1 AF4，开漏100kHz，与已有AHT20共总线 |
| BH1750 SDA | **PB9 / D14 / CN7-4** | I2C1 AF4；ADDR 保留已核对的板载默认低地址配置 |
| 独立红外发射板 DAT/IN | **PE11 / D5 / CN10-6** | TIM1_CH2 AF1，约38kHz、50%载波；仅适配高有效、3.3V兼容输入 |
| 独立红外接收头 OUT | **PA2 / A8 / CN10-11** | TIM5_CH3 AF2，1MHz双边沿捕获；OUT须不超过3.3V且低有效 |
| 外置温湿度 SCL/SDA | **PB8/PB9，CN7-2/4** | 只预留；实物型号、端子、供电确认后接，不新增GPIO |

**PA2 是 CN10-11，不是 CN9-11，也不是 K230 的物理 Pin11。** 红外选择的是独立发射板＋接收头，不接旧 YS-IRTM 的 TXD/RXD。红外两个模块的正反面丝印及芯片标识尚待确认，不按猜测的左右顺序接电。

## 电源与负载接线

| 模块 | 电源/负载 |
| --- | --- |
| 公共地 | NUCLEO **CN10-27 GND**、外部稳压电源负极、各模块GND共地 |
| NUCLEO 逻辑3.3V | 内侧 **CN8-7（3V3）**，可给已确认低功耗3.3V逻辑供电；电机/灯环不由此供电 |
| 灯环 | 稳压外部5V→5V/VCC；GND共地；DI建议经快速3.3→5V逻辑缓冲及约330Ω串阻，不能将5V接入PB11 |
| TB6612 | VM→外部稳压5V；VCC→3.3V；电机两线→AO1/AO2；未用BIN1/BIN2/PWMB接地，BO1/BO2留空。确认电机类型和启动/堵转电流适配驱动器；不通过面包板细线长距离供大电流 |
| 干簧管模块 | VCC→3.3V，GND→共地，DO→PE13；按模块丝印接，照片正反面方向不同 |
| GY-302 V322 | VCC先采用单一3.3V源低压试供；板载稳压器压差及芯片实际供电待测。SCL/SDA空闲高电平须为3.3V逻辑范围；不要遇到不应答就改5V |
| 外置温湿度 | 型号和载板供电未核实，先不通电。SHT3x的0x44/45与SHT20的0x40命令不同，目录还可能含Si7021；不能混用驱动 |
| 红外发射板 | 队友方案为5V驱动板，但实物额定供电、DAT高有效及3.3V兼容仍待确认；确认后外部稳压5V供电，DAT建议10k下拉；不可用GPIO直接驱动大功率红外LED |
| 红外接收头 | 候选3.3V供电、OUT低有效；必须按实际器件确认工作电压、脚序，测OUT高电平后再接PA2 |

若传感器由外部3.3V供电，外部3.3V**正极不与USB供电的NUCLEO 3V3正极并联**，只共地。模块之间并联分线SCL/SDA，不串接；每个排母孔只插一根线，用端子分线。多个上拉并联后的总阻值及总线波形需检查。8.4V电池只接符合规格的降压模块输入，不直连5V或3.3V端。

## 保留资源与频率冲突

- USART2 PD5 TX / PD6 RX：K230，CN9-6 / CN9-4，双向交叉接线、3.3V逻辑。K230 GPIO5（物理Pin11）TX→PD6；GPIO6（Pin13）RX←PD5；Pin9 GND共地。
- USART6 PG14 TX / PG9 RX：EC200U，CN10-14 / CN10-16，保持现有扩展板实际路径；不改AT口跳帽。
- USART3 PD8/PD9：ST-LINK日志与调试，115200/8N1；COM号由当前设备管理器识别，不固定为历史COM4。
- LCD继续现有SPI1 PA5/PA7、PF12 DC、PD14 CS；本PR不迁移DMA。板载AHT20 I2C1地址0x38、PC5光敏ADC保留。
- 灯环TIM2为800kHz；风扇TIM3为20kHz；红外TIM1为38kHz。TIM4为1MHz包络时基、无输出脚；TIM5为1MHz接收时基，IRQ均6、无DMA；TIM6保留HAL时基。
- **TIM1整个计数器已分给红外，不能再用PE9/TIM1_CH1驱动50Hz舵机。** 舵机暂不接，需另选计时器。不得同时运行旧YS串口红外任务。

## 队友按此顺序执行

1. 断电拍全景和每个模块端子近照；核对上表实际插孔。先确认独立红外模块、外置温湿度型号，未确认项不接电。
2. 不接电机和灯环大电流负载，测5V/3.3V及共地；再接负载，记录启动时VM是否跌落。掉压先处理电源及线阻。
3. 先核对当前固件启动版本。PR候选为 `ir-pulse-main-20261123.1`，烧录前保留现有固件；本PR未授权自动烧录，也未证明新候选硬件通过。
4. 当前main由AUTO拥有灯扇输出，`0`或`F0`触发安全关闭，B1短按恢复AUTO；数字1～4、F1～F4会被拒绝。不要按旧台架五档说明判断新固件故障；动作验收使用当前批准的AUTO场景，记录命令/控制日志与实物动作分别是否成功。
5. 干簧管用磁铁靠近/远离各3次，保存stable_do日志；安装闭窗位置后确认哪一电平表示闭窗，再做校准。只有一个闭窗传感器时只能显示关闭到位或未确认关闭，不能确认全开。
6. BH1750先单独接入，记录地址（0x23或0x5C）、valid和lux；遮挡/照明各3次。PC5保留原码，不与lux直接平均。外置温湿度确认型号后再实现驱动，先与AHT20并行对照，尚不做无依据的偏移补偿。
7. 红外先对队友匹配的演示接收板发送ASCII `Is`，再`Io`，保存原始帧/波形和接收日志。`Is`数据为`01 1A 41`，`Io`为`02 00 58`；自定义24位MSB先发、异或校验，不是标准NEC或空调协议。
8. 接收方向使用匹配的演示信号源验证24位解码；`Il`进入10s单帧学习、`Ir`重放、`Ix`终止。队列接受、定时序列结束、光学发射、目标执行要分别记录。没有匹配信号源/示波器时保留待验，不能只用手机相机证明载波和帧正确。

交回信息：模块正反面/全景照片、版本与HEX哈希、供电电压（静态/启动）、串口原始日志、红外时序/载波记录、动作视频、失败条件。缺少观测的项目填写“未测”，不写通过。公共MQTT字段/主题/优先级不变；亮度/档位/窗户/红外上云需另提扩展建议。
