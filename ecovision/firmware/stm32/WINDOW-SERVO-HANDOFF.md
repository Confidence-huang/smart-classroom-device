### 1.2 核心逻辑与关键参数

1. **PWM 时基与通道配置（`app_servo.c`）**：
   - 自动读取 `PCLK2` 与 `PPRE2` 分频，计算 `TIM1` 真实内核时钟（96 MHz），设置 `PSC = tim_clk_hz / 1_000_000 - 1`，实现 **1 MHz 计数（1 tick = 1 us）**。
   - `ARR = 19999` → 周期 **`20000 us`（50 Hz）**。
   - 脉宽范围：**`500 us`（0°）～ `2500 us`（180°）**，上电默认 **`500 us`（0° 待命位）**。
   - 角度换算公式：
     ```c
     pulse_us = 500U + (deg * 2000U + 90U) / 180U; // deg > 180 钳位到 180
     ```
2. **双舵机单向推拉互锁逻辑（`app_led.c`）**：
   - **机构特性**：外侧舵机（`ch=1`）从 `0° → active_deg` 把窗户推/拉开，退回 `0°` 时不会带关窗户；内侧舵机（`ch=2`）从 `0° → active_deg` 把窗户推/拉关，退回 `0°` 时不会带开窗户。
   - **非阻塞三步状态机**（在 `ledTask` 中以 `HAL_GetTick()` 推进，不阻塞 FreeRTOS）：
     1. `WIN_SEQ_RETREAT`：先让**对侧舵机**回 `0°`，等待 **`400 ms`** 确保完全让出空间；
     2. `WIN_SEQ_ACTUATE`：驱动**目标舵机**转到工作角（当前代码为 `30°`，可按实测修改），等待 **`400 ms`**；
     3. 归位收尾：将**目标舵机**退回 `0°` 待命位，状态恢复 `WIN_SEQ_IDLE`。
3. **执行方式**：
   - 通过 STM32CubeProgrammer 烧录台架 HEX（**切勿勾选 Full chip erase**，保留 `0x08160000` 私有配置区）。
   - 板子复位后 `ledTask` 延迟 650 ms 自动调用 `Servo_Init()`，立即在 `PE9` 和 `PE11` 输出 50 Hz / 500 us PWM。

## 3. 自然语言控制指令与串口底层映射

本机通过 `COM15`（ST-LINK VCP，`115200, 8N1`）直接与固件交互。向助手（Antigravity / Codex）下达自然语言指令时，会按以下规则解析并转换为对应串口字节流：

### 3.1 自然语言解析规则与动作映射

| 用户自然语言说法示例 | 解析规则 | 实际发送串口命令 | 执行动作与日志预期 |
|---|---|---|---|
| “让外面的舵机转到 60 度再回 0 度” | 目标=外侧(`A`)，角度=`S060`，延时后=`Z` | `BZ` → 等 250ms → `AS060` → 等 700ms → `Z` | 先确保内侧在 0°，外侧转 60° (`1167 us`) 后回 0° |
| “让里面的舵机转到 90 度再回来” | 目标=内侧(`B`)，角度=`S090`，延时后=`Z` | `AZ` → 等 250ms → `BS090` → 等 800ms → `Z` | 先确保外侧在 0°，内侧转 90° (`1500 us`) 后回 0° |
| “把内外两个舵机都回到原位/归零” | 两个通道均发 `Z` | `AZ` → `BZ` | 舵机 1 与舵机 2 均置为 `0° (500 us)` |
| “执行一次开窗动作” / “测试开窗” | 触发互锁开窗序列 | `O` | 内侧先归 0° (400ms) → 外侧转工作角 (400ms) → 归 0° |
| “执行一次关窗动作” / “测试关窗” | 触发互锁关窗序列 | `C` | 外侧先归 0° (400ms) → 内侧转工作角 (400ms) → 归 0° |
| “外面舵机加 5 度 / 减 5 度” | 选中 `A`，发 `+` / `-` | `A+` 或 `A-` | 当前角度 ±5°（钳位 `0~180°`） |
| “查一下干簧管状态” | 查询消抖快照 | `R` | 打印 `[REED_BENCH] query valid=... stable_do=...` |

### 3.2 PowerShell 串口直接控制示例命令

> 使用前确保 VS Code「串行监视器」已点击 **停止监视** 释放 `COM15`。

```powershell
# 示例：安全测试外侧舵机转到 60° 并返回 0°
$p = New-Object System.IO.Ports.SerialPort 'COM15', 115200, 'None', 8, 'One'
$p.ReadTimeout = 200; $p.Open()
$p.Write("BZ"); Start-Sleep -Milliseconds 300
$p.Write("AS060"); Start-Sleep -Milliseconds 700
$p.Write("Z"); Start-Sleep -Milliseconds 300
while ($p.BytesToRead -gt 0) { Write-Output $p.ReadLine().Trim() }
$p.Close()
```

## 4. 分别控制内外侧舵机与安全边界约定

1. **角度范围与方向约定**：
   - 软件允许输入范围：`0°～180°`（对应 `500～2500 us`）。
   - `0°` 约定为**机械退让待命位**（此时摇臂不顶着窗户）；`> 0°` 为**推/拉动作方向**。
   - **严禁直接发送 `S180` 驱动已挂接连杆的窗户**，标定时必须从 `30°` 起每次 `5°～15°` 递增试探。
2. **回零 / 复位条件**：
   - **上电复位**：`Servo_Init()` 强制将两通道置于 `0° (500 us)`。
   - **单步测试回零**：每次发 `Sxxx` 后延时 `500～900 ms` 务必发 `Z` 回零，防止长期堵转发热。
   - **互锁动作前强制回零**：驱动任一舵机前，必须先确认对侧舵机已处于 `0°`。
3. **串口异常处理**：
   - `S` 后必须在 **1000 ms** 内收齐 3 位数字（如 `S045`），否则超时重置并打印 `[SERVO_BENCH] ERROR incomplete command; use S000..S180`。
   - 收到非数字则立即中止解析并丢弃该命令，不影响控制主循环。

## 6. 最终实验现象、验证步骤与完成标准

### 6.1 最终应观察到的实验现象
1. 上电复位后，两颗舵机自动停在 `0°` 待命位，不顶窗、无持续异响、STM32 与 K230/4G 不重启。
2. 发送 `O`（开窗）时：内侧舵机先确保回 `0°`，400 ms 后外侧舵机平稳转到标定开窗角将窗户打开，随后退回 `0°`。
3. 发送 `C`（关窗）时：外侧舵机先确保回 `0°`，400 ms 后内侧舵机平稳转到标定关窗角将窗户关严，随后退回 `0°`。
4. 连续执行 5 次 `O → 等 2 秒 → C` 循环，机械无卡死、不互顶、外部 5 V 供电稳定。
