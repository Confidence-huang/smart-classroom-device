## 接线

VCC=模块支持的3.3V，GND共地；SCL=PB6，SDA=PB7，RES=PB8，DC=PB9。使用软件SPI，PB6/PB7不初始化为I2C。六针模块没有引出CS，内部CS/接口配置以模块电路为准，不臆造外部CS接法。保留SWD PA13/PA14。红外PA0暂不启用，蜂鸣器不驱动。本固件只用于F103，不适用于NUCLEO-F413ZH。

上电显示 `SPI OLED TEST`、`STM32F103 READY`、所用控制器候选配置及 `IR NOT ENABLED`；PC13按500ms亮灭节拍输出（实物LED存在、极性及亮度需确认）。使用复位默认内部HSI 8MHz，不依赖外部晶振。

## 2026-11-24 红外接入

### 引脚及页面

OLED仍为PB6/PB7/PB8/PB9；接收头OUT/S接PA0，接收头须支持3.3V供电，输出≤3.3V，GND与F103共地。NUCLEO发射端为PE11/CN10-6驱动独立发射板。两端独立供电时通过红外光通信，不需板间UART。F103保留SWD，BOOT0=0。

F103使用内部HSI 8MHz、TIM2_CH1/PA0、1MHz计数；F1交替切换捕获边沿。中断只缓存128个时间戳，主循环独占组帧和解码；过捕获/环溢出丢帧并重新等待下降沿。20ms静默结束一帧，严格使用现有ir_pulse_codec.c检查24位cmd/param/XOR0x5A、精确51段、脉宽及参数范围。不接受任意遥控协议，不放宽校验来假装收发成功。

页面显示IR RX READY、AC DEMO WAIT/ON/OFF、温度、模式、风速、RX/BAD、CMD/PAR、PA0 H/L、边沿E、异常ERR及运行秒数UP。AC DEMO为最后一次有效演示命令的本地状态，不是实物空调执行反馈。蜂鸣器未启用。
